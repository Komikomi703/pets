# 設計メモ

## 責任の分離

- `src/core/behavior.ts`: DOM/OSを知らない状態機械。操作優先、最短継続、性格と育成値による重み、追跡とクールダウン。
- `src/core/geometry.ts`: 符号付き物理座標、倍率、作業領域、画面復旧の純粋関数。
- `src/render/characters.ts`: 共通の描画・ヒットテスト・破棄インターフェース。猫は `cat.ts`、ググガガは `gugugaga.ts` のパーツ描画で、256×224・足元206を共通基準とする。ググガガだけ倍率0.875を適用し、実際の描画アルファから入力用64×56マスクを作る。Canvasは内部2倍解像度。
- `src/main.ts`: ペット画面のライフサイクル。描画30Hz（睡眠15Hz）、行動とIPC最大10Hz。IPC完了まで次の送信を待ち、連続障害時は最大8秒までバックオフ。非表示時は描画停止。キャラクター切り替えで描画・行動・音声を破棄し、古いフレームの完了を無視する。
- `src/platform/`: Tauriアダプターと独立したWebプレビュー。プレビューのDOM/LocalStorageによる操作はOS検証の代替ではない。
- `src/ui/settings.ts`: 日本語のお世話・設定画面。項目ごとのパッチ、リビジョン順の購読、保存失敗の表示。
- `src-tauri/src/model.rs`: 保存スキーマ、範囲検証、育成値。
- `storage.rs`: 正常な前回データのバックアップ、同期書き込み、同一ディレクトリ内の原子的な置換、破損の退避。未知の将来バージョンは上書きしない。
- `runtime.rs`: 唯一の永続状態、Windowsグローバルカーソル、入力透過、ドラッグ、自律移動、モニター復旧、間引き保存。
- `lib.rs`: 型付きコマンド境界、トレイ、単一起動、自動起動、ウィンドウと終了処理。

## Windowsと入力

猫専用の小さな透明ウィンドウを用いる。装飾・影・タスクバー表示・自動フォーカス取得を無効にし、設定画面や右クリックメニューは明示操作で開く。OSの`set_ignore_cursor_events`を切り替え、透明部分の入力を背後へ渡す。DOMの`pointer-events`だけでは実装しない。

猫の右クリックは、トレイと共通のOSネイティブメニューを開く。小さな透明ウィンドウの外にもメニューを表示できる。表示中は描画・自律移動を止め、猫ウィンドウの入力透過切り替えも抑える。メニューを閉じると通常動作に戻る。Webプレビューは同じ基本操作（隠す・設定・終了）をDOMメニューで再現する。

Rust側が約16ms周期でOSのグローバルカーソルを取得し、猫のアルファマスクと照合する。透明中もループは動作するため、猫の上にカーソルが戻れば操作を再開できる。集中モードは全域透過で、トレイから解除できる。マスクの送信は最大10Hz、入力透過のOS呼び出しは状態変化時のみ。余白の境界には4アートピクセルの量子化とポーリング遅延があり、非常に素早い境界クリックは実機確認対象。

左クリックの押下は猫からのIPCで開始する。Windowsの`GetAsyncKeyState(VK_LBUTTON)`で離されたことを検出するので、ウィンドウ外でもドラッグを終了できる。6論理px以上でドラッグになり、その後のクリック反応は抑制。ドラッグの基準は物理座標で保ち、DPI変化では猫内のつかんだ比率を維持する。画面作業領域はTauri 2の`Monitor::work_area()`を使い、負座標を保持する。画面構成を2秒ごとに更新し、切断時は近い画面へ戻す。

OS呼び出しの前にRust状態ロックを解放する。設定変更は専用のトランザクションで直列化し、GUIスレッドを待ち合わせで停止させない。終了時は自律ループを停止、最後の保存を待ってプロセスを終了する。

## 保存と気軽さ

保存先はTauriの`app_data_dir()/pet.json`。Windowsでは通常`%APPDATA%\com.madoneko.desktop\pet.json`。3秒以上の間隔、変更後2秒の静止、最大30秒で保存し、終了時に最終保存する。行動中の移動位置も間引いて記録する。保存失敗は画面に表示して再試行する。将来スキーマを開いた場合は保存を停止する。

非起動期間は減点しない。満腹度・元気には下限があり、死・病気・催促通知はない。スリープ復帰の大きなdtを移動には使わず、育成値の経過も制限する。

## 将来の拡張

キャラクター定義と倍率は `core/characters.ts`、共通の操作優先順位・行動は `core/behavior.ts`、固有の見た目は描画インターフェースで分離する。保存形式v2の `profiles` に名前と育成値を個別保存し、v1の猫データは自動移行する。Rustでは既存Runtimeを唯一の管理状態として維持。共通設定・トレイ・入力透過・移動ループは複製しない。音声は `ui/sound.ts` の `VOICE_FILES` に再配布条件を確認した録音を後から登録できる。モバイル版はOSアダプターと操作体系を別に設計する。
